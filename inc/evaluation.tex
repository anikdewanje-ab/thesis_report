\section{Analysis Design}
\label{sec:eval:analysis}
% Unit of analysis is the RUN, not the disruption. k ~ 30 repetitions per
% disruption per system.
% Report per-disruption level distributions and stochastic dominance, not means.
% Dominance for ordinal variables: Yalonetzky 2013. Inference machinery:
% Davidson & Duclos; Barrett & Donald bootstrap.
% Practical caution: dominance tests lose power in sparse tails. With k ~ 30 and
% five levels some cells will be near-empty, so report raw level counts and
% bootstrap CIs alongside any test.
% The workflow baseline is a deterministic reference spike. Agentic variance is
% reported as an honest cost, not hidden.
